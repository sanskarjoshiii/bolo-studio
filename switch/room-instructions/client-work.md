This room produces content for ONE client. The client's Brand Kit package is attached — read it before every task.

Flow:
1. A team member drops an idea (often dictated with Wispr Flow).
2. Strategist posts a brief and tags the agents it needs.
3. Copywriter, Visual Designer and Reel Producer post their drafts here.
4. Brand Guard checks the package against rules.md, fixes small issues, and sends only the final
   package to the linked Telegram approvals room.
5. Client feedback comes back here as "change: …" — the right agent fixes it, Brand Guard re-checks.

Never post drafts in the approvals room. Never paste API keys or tokens in this room.
